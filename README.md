## Project Topic: DimEmployee Sales Analysis

### Project Overview
This Data Analysis Project helps to generate the sales performance of the organization by analyzing how well they made sales and if they literally meet up with their sales target for the previous years and also to know how many of the sales persons are really meeting their targets.

So we are to tell a compelling story around this particular data.

### Data Sources

The primary source of data used is DimEmployee Sales CSV and this is an open source data that can be freely downloaded from an open source online such as Kaggle or FRED or any other data repository site.
